# FreeBand support

Start with the [FreeBand installation and pairing guide](docs/FREEBAND_INSTALL.md) and [public beta release notes](docs/releases/freeband-public-beta.md).

For bugs, setup questions, or feature requests, search [FreeBand issues](https://github.com/austin17022/freeband/issues), then [open an issue](https://github.com/austin17022/freeband/issues/new/choose) if needed. Send FreeBand reports to this repository.

A useful report includes:

- FreeBand version and build, iPhone model, iOS version, and WHOOP model.
- Installation method, such as AltStore Classic, SideStore, Sideloadly, or an Xcode build.
- Steps to reproduce, expected behavior, and what happened instead.
- The exact error message, or a screenshot with personal details removed.

GitHub issues are public. Do not attach full health databases, `.noopbak` backups, food logs, raw strap logs, Apple account details, or API keys. If a short diagnostic excerpt is needed, remove health readings, device identifiers, names, and credentials before posting it.

For an app that no longer opens after a signing period expires, try the sideloader's refresh process first. **Do not uninstall FreeBand as a troubleshooting step:** its backup currently omits Weight loss food logs, weigh-ins, and goals. See [updating safely](docs/FREEBAND_INSTALL.md#update-an-existing-install).

This is a public beta with no promised support response time. FreeBand is independent of WHOOP, Inc. and is not a medical device.
